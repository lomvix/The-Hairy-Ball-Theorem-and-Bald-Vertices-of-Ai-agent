# The Hairy Ball Theorem and Bald Vertices of AI Agents

Research on when an AI agent's observable state is sufficient to predict its
future behavior.

- [Current WP1–WP6 findings](research/PUBLIC_STATUS.md)
- [Methods and interpretation rules](research/PUBLIC_METHODS.md)
- [Selected stage reports](reports/README.md)

The published code is a small, offline, synthetic-testable subset of the
analysis. It does not include benchmark conversations, raw model responses,
credentials, provider configuration, or complete run artifacts. In particular,
the current evidence supports next-step agent-only analysis, not a validated
closed-loop sufficiency claim.
