# WP5-B 三臂请求语境复核（2026-10-15）

状态：`REVIEW_COMPLETE_AGENT_ONLY_ABLATION`。已逐条阅读冻结计划 12 个锚点的待遮蔽 Agent 消息与紧随其后的用户回复，未改动计划或原始请求。复核目标是判断“遮蔽一条先前助手消息、但保留用户与工具可见文本”是否为可解释的**历史缺失敏感性**干预；它不要求编辑后的对话等同自然生成的闭环历史。

- 选中锚点序号 0、2、3、4、9：用户提供身份/订单检索所需信息；遮蔽后仍有可理解的当前输入。
- 序号 5、6、10、11：用户提出明确动作请求、取消原因或排障观测；遮蔽后仍可解释，但先前 Agent 的解释或指导被移除。
- 序号 1、7、8：用户明确提及先前 Agent 给出的报价、升级建议或商品替代选项。遮蔽后这些信息在最新用户回复中仍有残留，可能也出现在既有工具结果中；这是**高语境依赖**子组。保留在计划中，但必须单独报告，不能把差异归因于纯粹话语风格，也不能称作自然近状态配对。

12/12 锚点可用于预定的 Agent-only 人工历史遮蔽试点；0 个因工具调用链破坏或完全无从解释而剔除。此复核只支持发送冻结计划中的三臂请求，不能证明 User Simulator 或 Environment 状态可恢复。三臂只观察模型下一步响应；工具调用不执行。
