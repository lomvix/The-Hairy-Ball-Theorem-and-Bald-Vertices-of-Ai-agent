# WP5/WP6 可观测状态配对审计（2026-10-14）

本轮只分析现有 WP5/WP6 样本，新增 API attempt 为 0。目的：区分“B0 几何近邻”与“仅先前 Agent 历史不同”的可解释配对，并核对自然运行与 WP6 重复样本的下一步动作。

## 状态表示与配对结果

`src/behavioral_state/features.py` 中的冻结 `B0_CURRENT` 使用有效请求里**最后一个** USER、TOOL_RESULT、POLICY 原子的各 32 维投影，加上截断、工具与质量标志；没有独立的身份资料、请求目标、确认状态或更早用户消息槽。`B1_HISTORY_2` 在 B0 上增添两个先前 Agent 话语槽。因此 B0 的零距离只证明该压缩表示相同，不证明完整有效请求或完整可观测历史相同。

审计 `handoff_v5/history_aliasing_candidates.parquet` 的 3,445 个同条件跨运行配对，并按 `anchor_inventory.parquet` 的请求引用读取实际消息；比较消息文本/结构，不使用未来标签重新筛选：

| 范围或条件 | 配对数 |
| --- | ---: |
| 全部同条件跨运行配对 | 3,445 |
| WP5 几何预选、B1 历史槽不同 | 273 |
| 预选中最后一条用户消息完全相同 | 37 |
| 再要求最近一条工具结果相同（也包括双方均无工具结果） | 30 |
| 上述 30 组中，所有更早用户消息也相同 | 0 |
| 全部 3,445 组中，所有非 Agent 消息逐条完全相同 | 2；均未预选，且 B1 历史距离为 0 |

这 30 组来自 5 个任务，三个冻结投影种子的 B0 距离均为 **0**，但每组更早用户消息序列都不同。因此它们是可复查的**表示碰撞/信息压缩案例**，不是隔离了 Agent 历史效应的因果对照。预选中的其余 243 组至少在最新用户消息或最近工具结果上不同。既有 WP6 三组分支配对的最新用户消息也全部不同；其中 airline/retail 的高动作 TV 不可归因于隐藏历史或 B0 不充分。

对冻结自然运行的粗粒度 `ACT`/`COMMUNICATE` 标签做事后描述：30 组 B0 零距配对中有 2 组标签不同（retail、telecom 各一组）；其他 243 组中有 61 组不同。这些比较既受更早用户消息差异影响，又有同任务/同运行的依赖，**不能**把 `2/30` 或 `61/243` 当作独立样本的充分性检验或效应量。两组差异的 decision ID 分别为：

- retail：`decision_9cd17b4723d5ccb5837f074c68277491e5a9ab9769f77200b28f45ee8a359d34`（自然 `COMMUNICATE`）与 `decision_9f6aa6332d6bd54186269d4677ef52fc2a615864021e34f722e2dd8f78158398`（自然 `ACT`）。
- telecom：`decision_c665d8d7c19f107e17acce2704a8f2a5d915ae283c1d10e0e6f588f22fad4b63`（自然 `ACT`）与 `decision_e77553a07a61295c428d78653e9aad50a73c9d07bcd306280cda5f25606b5677`（自然 `COMMUNICATE`）。

## 自然运行与现有 WP6 重复样本

将 24 个锚点的自然下一步动作与各自 8 条 Agent-only 分支按“调用工具 / 不调用工具”比较（分支的 `COMMUNICATE_OR_STOP` 合并为不调用工具）：21/24 锚点的 8 条分支全与自然动作同类；2 个锚点各有 7/8、1/8 同类；1 个 retail 随机对照锚点自然动作为 `COMMUNICATE`，但 8/8 分支均调用 `calculate`。这一例恰是上述 retail 零距配对的一端。它提示单次自然动作不能自动代表后续重复请求的动作分布；也可能涉及请求种子、运行时间或服务状态差异，现有数据不能区分。8 次重复且没有闭环工具执行，不足以判定长期策略或任务成败。

## 当前判断与下一步

现有数据支持两个有限结论：`B0_CURRENT` 有真实的表示碰撞；同一请求在部分锚点上有可观测的下一步动作分支。现有几何配对**不支持**“只改变 Agent 历史会改变行为”的确认性主张。后续若继续 WP5-B，应优先用已归档样本筛选完整非 Agent 可见上下文一致的锚点，或者显式设计固定用户/工具观察、只改变先前 Agent 话语的受控请求；进入付费采样前另列计划与预算。现阶段不需要为了这份审计新增采样。
