四个随机对照各 8 次，下一步结构性动作都与原 Pilot 一致。上述显著的表面切换，尤其是最后一个 retail 锚点，提示跨采样时段/服务条件值得检验；**现阶段不能断言是时间漂移，更不能断言是模型更换**。

重要的独立性限制：本块一个 retail 重点锚点的 24 次响应只有 **2 个不同的 response ID / choice payload**，telecom 重点锚点只有 **4 个**；相应的 provider request ID 各有 24 个不同值。两个 Claude 随机对照也分别只有 4/8、3/8 个不同 response ID。可能存在确定性重放、代理缓存或其他服务端机制；不能把复用 ID 的请求当作独立随机 draw，也不能仅凭复用 ID 确定具体原因。后两块将按原计划观察 ID/动作是否随时间改变；推断时并列报告按 API attempt 与按不同 response ID 去重的敏感性结果。
