# Public research reports

This directory contains selected WP1–WP6 research and implementation reports.
The published copies preserve research methods, counts, test results, and stated
limitations. Fifteen reports have local absolute paths or local secret-file
references replaced with placeholders; the original workspace reports are
unchanged.

The public set omits operational security records, workspace-environment logs,
network authentication and transport diagnostics, and repetitive acquisition
checkpoints. It also omits raw benchmark conversations, request/response payloads,
run artifacts, credentials, and private provider configuration. Thus these
reports document the findings but do not constitute a public raw-data release.

Start with the [research status](../research/PUBLIC_STATUS.md) and
[methods](../research/PUBLIC_METHODS.md). The original task-level evidence is
retained privately; unavailable fields and unvalidated closed-loop restoration
remain explicit limitations rather than inferred results.
