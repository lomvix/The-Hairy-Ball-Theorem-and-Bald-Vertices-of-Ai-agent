# WP5-B Agent 历史干预：离线机制复核

日期：2026-10-15。此报告只复核已完成的 WP5-B 响应，不新增 API 请求。来源为 `runs/wp5b_history_intervention_analysis_v2/` 的 216 行结果与原始响应；派生数据为 `runs/wp5b_history_mechanism_v1/`，按响应记录可见文字字符数、可报告的推理/文字 tokens、工具名与规范化参数的哈希，以及按 12 个独立任务聚合的比较。原始请求和响应未修改。

## 实际结果

- 216 个计划行均已尝试；210 成功、6 个传输结果不确定。72 个三臂重复中 67 个完整：held-out TEST 35/36，CURATION_DIAGNOSTIC_ONLY 32/36。67/67 个完整三臂的粗动作一致；它只说明这些观察到的下一步均落在同一粗动作类别，不证明历史信息充分。
- 对完整三臂比较**工具名加参数**（忽略 provider 生成的 call ID，保留调用顺序）：A/B 相同 64/67，A/C 相同 66/67，B/C 相同 65/67。全部差异来自选中索引 7 的**同一个探索性 airline 任务**；其余 11 个任务，包括 6 个 held-out TEST 任务，在观察到的完整配对中均无工具参数差异。这里的 3 次不同不是 3 个独立任务的复制。
- 索引 7 的用户请求是先把 basic economy 升至 economy、再单独考虑不停站航班。三臂观察到的下一步都是只读航班搜索，没有执行升舱写操作；Agent-only 单步设计不能据此断言最终流程完成或失败。A/C 主要只搜索第一航段 EWR→MIA，B 有 2/6 次同时搜索后续 MIA→LAX 航段；A 有 1/6 次改搜 EWR→LAX 的一次中转方案。相对于 placebo C，B 的两次差异与 A 自身一次偏离都发生在同一任务，既显示局部路径敏感，也提示基础随机/运行波动，不能作总体因果外推。该锚点最新用户话语依赖此前 Agent 对行程和升舱选项的解释；遮蔽它并非自然同义改写。
- 索引 6 的取消请求：成功响应为 A 6、B 4、C 5，分别只有 3、1、2 种不同 choice payload。人工检查这 6 种不同可见回答，均说明当前预订不满足取消条件，没有出现“改为批准取消”的行为。B 的平均总输出用量 1,769 tokens（A 约 961、C 约 808），但其 1,587 是 provider 报告的推理 tokens，仅 182 是可见文字 tokens；A/C 平均推理约 820/663、文字约 140/145。平均可见字符 B 771、A 611、C 653。因此先前执行报告若把总输出 tokens 当成回答长度，解释并不准确：可见回答略长，**用量差的大部分来自不可见推理**。B 的 4 次成功是同一个 choice payload，不能充当 4 次独立复现。
- 210 个成功响应中，只有 48 个提供与总用量相符的推理/文字 token 拆分；有些响应把两个细项都填 0、总输出却非 0，本复核将这种细项标记为未报告，绝不解释为真实的零推理。用户可见文字字符数独立从 message content 计算。210 个响应中 123 个为单工具调用、2 个为双工具调用、85 个未调工具。

## 证据边界及下一步

这是一项小型、人工筛选锚点的 Agent-only 干预。分析单位应是 **12 个任务**，而不是 216 次调用；其中 held-out TEST 只有 6 个任务。6 个传输不确定结果不能当作动作相同：TEST 的一条缺失属于 C 臂，故 TEST 仅能说 35 个完整三臂一致；探索集另有 5 条缺失。相同 choice payload 可能跨不同 response ID 重现，不能以不同 ID 证明独立采样。请求时序、provider 缓存或复用也未被完全排除。严格 WP5-B 行为充分性仍为 `UNIDENTIFIED`，有效 Closed-loop 检查点仍为 0。

研究上最有效的下一步不是继续扩充同一任务的重复次数，而是预先选择更多**不同任务**，把高语境依赖任务与可独立理解任务分层，预定工具参数/最终任务结果两个终点，并把完整 Closed-loop 恢复作为单独实验。若再做付费实验，应另定预算和授权；本轮未请求或使用新预算。
