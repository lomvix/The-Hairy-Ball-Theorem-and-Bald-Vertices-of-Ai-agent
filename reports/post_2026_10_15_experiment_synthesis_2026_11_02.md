# 10 月 15 日后 WP1–WP6 实验推进与样本综述

截至 2026-11-02。本文件是公开级、只读的阶段整理；数字来自已冻结的本地报告和账本，没有新增模型、embedding 或评分调用。研究总体仍是 WP1 分层冻结的 60 个 tau2 Task；结论只覆盖其中具有观察和恢复支持的区域。本文不包含原始对话、工具参数值、身份资料、密钥或逐条响应。

## 结论先行

10 月 15 日后，研究从“同请求下一动作”推进到应用层双恢复、真实 User/工具闭环和受控历史信息三臂实验。因而 10 月 15 日报告中的“尚无真实闭环分支”是**当时状态**，不能继续当作最新样本描述。新实验确实观察到历史信息遮蔽后的重新询问、执行顺序改变和局部数据库转移；但严格自然 Type-B-Clean 历史对照仍为 **0 个独立 Task**，且尚无冻结约化状态表示后的独立前瞻预测确认。三个 Gate 分别是：自然历史效应 `UNIDENTIFIED`；受控输入敏感性 `EXPLORATORY`；多步状态充分性 `NOT_ESTABLISHED`。

## 初步机制分析：什么样的样本最有信息

1. **保留旧事实且当下需要使用。** 两个 Retail 地址锚点显示相近模式：A/C 多数分支实际执行目标地址修改，B 遮蔽后不改；其中一组为 A 4/4、B 0/4、C 3/4，另一组为 A 3/4、B 0/4、C 3/4。两组均是探索性且同域；一个锚点筛选时看过较晚归档续行，不能合并为确认性发生率。它们还说明固定 Agent2 太早，相关写入常在 Agent3–6。
2. **旧事实可能被 User 重新获得而终态收敛。** 双域 Retail 新地址锚点的 B 臂 3/4 次通过新 User 消息重新明确“无单元号”，但三臂 12/12 均正确写入空的第二地址行；Telecom Data Saver 锚点的 B 臂 4/4 触发重新检查，A 为 0/4，最终三臂设备状态仍相同。信息缺失可先改变问询/检查路径，之后被新信息消除。
3. **Agent 指令的执行语义可制造暂时环境风险。** 新 Telecom 漫游锚点在 B 臂 4/4 出现 User 再述漫游，A/C 均 0/4；一条 B 路径在设备漫游原本为 true 时按“开启”指令调用 toggle，先变 false 再恢复 true。三臂最终均 true；只看终态会漏掉中间转移。此为单次事后机制观察，不是 Task 级风险率。
4. **表面强效也须检查编辑合法性和基线波动。** Airline 生日锚点 A/C 各 4/4 正确更新，B 0/4；但 B 在日期字段使用非日期占位符，工具契约未强制格式验证，且候选选择时已看过较晚提案，故不能列作严格三臂证据。程序性 User 能力锚点则 A–B 首轮 0/4 不同、Agent2 状态 0/4 不同，说明并非所有旧历史遮蔽都会分化。
5. **统计与预测对象必须分开。** 10/27 预注册闭环的 3/35 Agent2 差异集中一个 Task；10/30 P2 的后期可观察性下降；11/02 Retail 地址效应又主要在较晚动作时点。证据支持“局部输入敏感和路径异质”，尚不支持自然历史独立效应、跨域稳定效应或约化状态充分/不充分的确认性判断。

## 当前根因优先级与下一阶段

首要根因仍是自然共同支持为 0。其次是合格历史事实的稀缺与重新获取：受保护当前消息常重述旧事实，结构化 ID/日期/枚举很难合法遮蔽，或留存字段可反推出被删信息。第三是固定 Agent2、纯工具 L2 与最终精确 DB 哈希对多步机制不够：通信、User 操作、相邻工具写入、暂时状态和自然终止需按完整 Agent 序号分别编码。第四是独立 Task/域支持、A/C 基础波动和右截尾；增加同一 Task 的 seed 不能补足这些缺口。Provider 隐含状态与响应复用仍是证据限制，但不应代替核心识别问题。

建议先在尚未使用的独立锚点上冻结“事实来源—全部重复表达—当前动作依赖—首次重新获取时点—合法 C 臂”资格卡；在付费前固定事件锚定终点与固定 Agent2 比较终点。自然线继续单列，严格 Type-B-Clean 未达原 6 Task 门槛时不做确认性检验。表示线须在**未用于设计**的独立 Task 上，比较原约化状态与显式“已知事实、待执行步骤、User 能力、实际设备值、信息新近度”扩展状态的前瞻预测；不能用同一批机制案例既开发又确认。深入分析的材料索引与具体复核问题见 `research/POST_2026_10_15_DEEP_ANALYSIS_GUIDE.md`。
