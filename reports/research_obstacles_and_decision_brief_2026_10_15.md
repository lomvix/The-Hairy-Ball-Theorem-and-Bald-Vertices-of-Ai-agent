# 当前研究阻碍与决策材料（2026-10-15）

## 一页结论

当前最重要的阻碍不是缺少 API 调用总量，而是**可比较历史的识别设计、独立任务支持和闭环检查点保真**。现有证据足以研究“相同有效请求下的下一步动作”及少数人工历史干预的局部敏感性；尚不足以确认约化状态对未来行为充分，也不足以估计 Agent–User–Tool–Environment 的多步转移分布。严格 WP5-B 结论保持 `UNIDENTIFIED`，有效 Closed-loop 分叉数为 **0**。这不是软件测试失败，而是研究估计对象所需证据尚未建立。

本材料依据已归档的任务书、冻结数据和阶段报告，不重新采样、不重跑模型。下列“阻碍”按它妨碍的科学结论排序；技术或平台问题只有在影响识别、独立性或外推时才列入。

## 核心阻碍：按科学影响排序

### 1. 自然近状态配对没有隔离“历史”变量（最高优先级）

在冻结的 3,445 个跨 run 同条件配对中，**没有**一组“完整非 Agent 输入相同而先前 Agent 文本不同”的自然配对。旧版 273 个几何候选里，最后用户消息和最近工具结果均相同的仅 30 组；再要求更早用户消息序列相同则为 **0**。首轮 airline/retail 的大经验 TV 可由当前提供的身份信息、目的地和任务进度差异解释，不能归因于省略历史。[可观测状态重筛](./wp5_observable_state_v2_2026_10_15.md)、[Agent-only 配对分析](./wp6_agent_only_research_findings_2026_10_14.md)

**后果**：现有自然配对可暴露表示设计的缺口，但不能识别先前 Agent 历史的独立因果作用。继续对这 273 组重复采样，不能消除原有的用户/工具条件混杂。**解锁路径**：把当前目标、身份资料是否已提供、最近确认与完整更早用户/工具序列纳入匹配或显式条件；将“自然可比”与“人为遮蔽”两类估计对象分开。若自然支持仍为零，就应明确放弃在这批归档数据上估计该历史因果效应。

### 2. 独立任务与确认性支持不足，重复调用有伪复制风险

WP5-B 的 216 次调用只覆盖 **12 个任务**，其中 held-out TEST 仅 **6 个**；5 个三臂重复不完整。动作参数差异全部集中于一个探索性 airline 任务。该任务 B 对 C 有 2/6 次额外搜索第二航段，A 对 C 也有 1/6 次不同搜索；这种任务内波动不能转写为跨任务可重复效应。另一个任务 B 臂 4 个成功响应只有 **1 种** choice payload。更早的 WP6 时间块中，成功响应/不同 response ID 为 128/77、125/85、128/128；不同 ID 本身也不能证明独立推理。[WP5-B 机制复核](./wp5b_history_mechanism_2026_10_15.md)、[WP6 时间块分析](./wp6_temporal_distribution_evidence_2026_10_15.md)

**后果**：以 attempt 数做置信区间会过窄；零次观察到差异不能证明差异概率为零，更不能支持跨任务总体结论。**解锁路径**：优先增加**不同 Task UID** 的预注册确认锚点，按 Task/Anchor 聚类报告区间；任务内重复用于估计本任务的随机核，而非冒充独立任务。具体样本量需先规定最小值得检测的差异、主要动作粒度和预期复用/失访，再算预算；现在不能给出可信的“再采 X 次即足够”。

### 3. 缺少有效的完整闭环恢复，无法验证多步充分性

Pinned tau2 的 batch resume 不是任意决策点恢复。本地重放探针已覆盖三个域和三模型中的 9 条环境变更前缀并通过本地签名，但 User Simulator 的 provider 侧隐状态/会话不可观察，尚无偏离后 User 交互、工具副作用与终局的隔离分叉核验。按集成契约，LEVEL-1 精确 Agent 请求只支持 Agent-only；LEVEL-3 才能称有效 Closed-loop。当前 LEVEL-3 数为 **0**。[WP6 任务书](../work_packages/WP6_Checkpoint_Replay_Branch_Sampling.md)、[能力审计](./wp6_static_capability_2026_10_14.md)、[跨域重放](./wp6_cross_domain_replay_2026_10_14.md)

**后果**：目前不能估计 `L=2/4/8` 的 Agent–User–Tool–Environment 未来分布、任务终局差异或严格的 WP5-B 多步充分性；单步调用只观察模型提议，不观察工具执行。**解锁路径**：研究并验证可控的 stateless User 重建，或提供可审计的服务端会话恢复；对每锚点至少两次独立恢复、环境克隆和偏离后行为核验。若不能控制关键隐状态，就把研究主张限定为 Agent-only，不以“近似闭环”改名绕过此障碍。

### 4. 候选状态与动作终点的粒度仍会遮蔽关键机制

冻结 `B0_CURRENT` 是有意有损的 646D 表示；原几何近邻未保留足够的当前用户/工具区别。身份资料、当前目标、最近确认等尚未形成充分覆盖的语义状态；字面邮箱仅命中 15/2,831 个状态，简单肯定/否定词表仅命中 2 个。粗 `ACT`/`COMMUNICATE` 合并不同工具参数与沟通内容：WP5-B 的 67/67 粗动作相同，但同一任务出现不同航段搜索；首轮 WP6 的 8 个锚点只有文本层变化，未对全部文本做语义标注。[可观测状态重筛](./wp5_observable_state_v2_2026_10_15.md)、[机制复核](./wp5b_history_mechanism_2026_10_15.md)、[Agent-only 研究发现](./wp6_agent_only_research_findings_2026_10_14.md)

**后果**：过粗终点会漏报实质变化，整段文本哈希又会把同义表达算成变化；表示中的信息缺口与策略随机性容易混淆。**解锁路径**：预先冻结层级终点：①执行/交流/拒绝；②工具名、调用次数和规范化参数；③经盲审定义的沟通语义；④闭环完成/环境转移。对状态本身增加可观察的任务目标、身份与确认字段，同时保留 `UNKNOWN`，不把用户模拟器私有状态注入 Agent 表示。

### 5. 时间、代理路由和响应复用无法与随机波动完全分离

同一有效输入在 WP6 时间块中出现局部动作比例与 response 复用状态同时变化。第三块实际被提前约 18 小时 40 分执行，原定 +36 小时只是名义时间标，因此不能称预注册时间漂移。DMX 的路由、缓存和服务端会话状态不可完全观察；WP5-B 虽有 210 个不同 response ID，却只有 191 个不同 choice payload。部分请求传输结果不明，不能当作模型行为缺失或失败。[时间块报告](./wp6_temporal_distribution_evidence_2026_10_15.md)、[WP5-B 执行报告](./wp5b_agent_history_intervention_execution_2026_10_15.md)

**后果**：局部比例变化可能是随机性、缓存/路由或运行条件变化的混合；跨块比较不能被解释为因果模型漂移。**解锁路径**：若时间效应是研究问题，重新冻结真正按实际 dispatch 时间执行的交错/随机化块，同一锚点与对照同批出现；同时保留 response ID、choice payload 和 provider 元数据两种敏感性口径。若不是核心问题，先将采集块当作协变量，不额外付费追逐时间结论。

## 次级限制：需要记录，但不应喧宾夺主

- **样本池与外推**：WP1 为 60 个任务，WP5-A TEST 为 9 个任务；全部 60 个任务曾进入 WP2 Scout，12 个 Curation Diagnostic 并非全新独立确认。现有数据对所选 tau2 任务/模型/时间段有效，不自动代表其他 Agent、任务分布或生产系统。[WP5-A 初筛](./wp5_a_initial_2026_10_13.md)
- **测量与轨迹缺口**：WP4 替代模型已获用户批准且向量完整，但与任务书默认 embedding 不同，跨 embedding epoch 的坐标比较受限。WP5 初筛中所有 3,640 个决策的 context truncation 状态为 `UNKNOWN`，202 个 WP4 Agent 证据行为 `PARTIAL_MAPPING`；WP3 有 35 个 `calculate` 效果仍为 `UNKNOWN`。这些缺口不等于当前 Agent-only 结果无效，但会限制完整状态与环境转移解释。[WP4 冻结](./wp4_last_gaps_frozen_2026_10_13.md)、[WP5-A 初筛](./wp5_a_initial_2026_10_13.md)、[WP3 阶段报告](./wp3_checkpoint_2026-10-13_v3_stage_cli.md)
- **有价值但尚未完成的安全异常研究**：retail 身份查找锚点在三个 WP6 时间块里出现 44 次模型**提议**以请求中没有来源的邮箱参数查找用户；工具未执行，不能把它写成实际数据泄露或任务失败。该现象值得单独追踪参数来源和下游结果，不能混入历史充分性主检验。[WP6 时间块报告](./wp6_temporal_distribution_evidence_2026_10_15.md)
- **付费接口与成本**：DMX 发生过 SSL/传输不明，真实失败请求用量与货币价格未知。它影响预算和缺失机制，但不是目前严格充分性无法成立的首要原因；即使网络完全稳定，前述识别与闭环问题仍在。[WP4 冻结](./wp4_last_gaps_frozen_2026_10_13.md)、[WP5-B 执行](./wp5b_agent_history_intervention_execution_2026_10_15.md)

## 可选择的研究路径

| 路径 | 能回答的问题 | 关键新增工作 | 仍不能宣称 |
| --- | --- | --- | --- |
| **A：收束为 Agent-only 机制论文/章节** | 同一有效请求下的下一步动作随机性，以及人工省略 Agent 历史对局部工具/回答的敏感性。 | 增加不同任务的预注册确认样本；更细终点与 Task-cluster 不确定性；明确人工干预和 provider 复用。 | 完整 Agent 状态充分、闭环任务成功率、自然历史因果效应。 |
| **B：继续追求严格 WP5-B/WP6** | 受控可恢复区域内，近状态不同历史的多步未来条件分布是否一致。 | 先解决 User/Env/Tool/Orchestrator 完整恢复与隔离；再冻结有自然支持的状态配对、随机对照和分叉预算。 | 有限支持区域以外的数学全局充分性。 |
| **C：先修订状态/匹配，再决定是否采样** | 哪些当前可见变量解释旧版几何近邻的假混叠；新表示是否能找到可比较支持。 | 离线构造按任务目标/身份/确认/工具历史分层的版本化状态与支持度审计；只在有支持处设计确认性请求。 | 没有新独立分叉时，不能从离线预测增益直接确认行为充分。 |

**建议顺序**：先做 C 的零付费支持度/终点预注册；同时单独推进 B 的恢复可行性，不把它绑在追加 Agent-only 采样上。若完整恢复仍不可实现，选择 A 并主动收窄论文主张。若需要新的付费采集，应先冻结任务级样本计划、预期可检测差异和硬预算，再请求授权；既有额度不自动延续。

## 需要研究负责人明确的三个判断

1. **主要估计对象**：先发表/报告 Agent-only 的局部策略敏感性，还是把完整闭环充分性作为不可降低的主目标？两者需要不同的实验基础。
2. **确认性终点**：以工具名及参数为主，还是以完整任务/环境结果为主？粗 `ACT` 一致与实际工具参数差异在现有数据中同时成立。
3. **外推范围与最小有意义差异**：目标是这 60 个 tau2 任务的有限支持描述、跨新任务泛化，还是更广泛 Agent 理论命题？在此之前，不宜用“达到足够样本量”作无定义门槛。
